Impact Range Assessment (IRA): An Interpretable Sensitivity Measure for Machine Learning Regression Modelling


Jihao You, Dan Tulpan, Jiaojiao Diao, Jennifer L. Ellis
[stat.ME]

While machine learning regression models capture the relationship between predictors and the response variable, they often lack intuitive methods to help modelers understand how sensitive model predictions are to changes in individual predictors. To address this limitation, we introduce a model-agnostic interpretability method called Impact Range Assessment (IRA), which quantifies the sensitivity of model predictions to changes in each predictor by measuring the range of predicted responses as the predictor varies across its observed range. Validation using synthetic linear and nonlinear datasets demonstrates that relevant predictors produced higher IRA values than irrelevant ones. Moreover, repeated evaluations produced results aligned with those from the single-execution analysis, confirming the method’s robustness. For demonstration, two benchmark datasets were used to evaluate IRA across five machine learning regression models, yielding model-specific sensitivity rankings and supporting IRA’s applicability as a complementary sensitivity analysis tool alongside feature importance methods such as permutation feature importance and SHapley Additive exPlanations (SHAP).
